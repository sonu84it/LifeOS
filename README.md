# LifeOS-Agent 🧠💼

An autonomous AI operating system for life planning, built for the Google Cloud Rapid Agent Hackathon.

---

# 📖 Introduction

What if AI could do more than answer questions?  
What if it could actually help people achieve major life goals?

Welcome to **LifeOS-Agent**. Instead of building just another reactive chatbot, LifeOS-Agent is a proactive, autonomous AI chief-of-staff designed to:

- Remember you and your context
- Plan and track long-term goals (like buying a house or retiring)
- Adapt dynamically as your life circumstances change
- Execute multi-step reasoning workflows

---

# ⚠️ The Problem

Modern AI tools are mostly reactive. You ask a question, they answer, and then they forget everything.

But real-life goals like:

- Buying a home
- Health transformations
- Career growth
- Financial independence

require:

- Long-term planning
- Persistent memory
- Dynamic adaptation
- Continuous tracking

This is where **Agentic AI** becomes powerful.

---

# ✨ Key Features

## 🧩 Goal Decomposition Engine

Converts vague goals like:

> "I want financial freedom"

into structured, execution-ready milestone plans using Gemini’s structured JSON generation.

---

## 📈 The "What-If" Simulator

Real-time visual trajectory forecasting.

Ask questions like:

- "What if my salary increases?"
- "What if inflation changes?"
- "What if I save more every month?"

and watch your financial or life timeline recalculate instantly.

---

## 💬 Contextual Agent Chat

A dedicated AI assistant that reasons based on:

- Active goals
- Savings rates
- Simulation trajectories
- User history and context

---

## 🧠 Persistent Intelligence (Vision)

Utilizes **Model Context Protocol (MCP)** to interact with long-term memory systems, creating emotional and strategic continuity over months and years.

# 🚀 How to Run Locally

Because this prototype is built using zero-dependency static files, running it is incredibly simple.

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/lifeos-agent.git
```

## 2️⃣ Open the Project Folder

```bash
cd lifeos-agent
```

## 3️⃣ Launch the App

Simply double-click:

```bash
index.html
```

or open it in your browser.

> **Note:**  
> To use the live Gemini Auto-Replan and Chat features, an active API key must be configured in the script.

---

# 🌐 Live Deployment

This prototype can be hosted directly on GitHub Pages.

## Steps

1. Go to your repository settings on GitHub
2. Navigate to the **Pages** section
3. Select **Deploy from a branch**
4. Choose the `main` branch
5. Save changes

Your agent will be live in minutes 🚀
